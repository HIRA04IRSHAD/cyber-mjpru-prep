## End-sem 2025-26 (paper code 25280)

**B.Tech (Seventh Semester) (Main/Back) Examination 2025-26 · CS-453T (EC/CSIT) · Cyber Security**<br>
Time: Three Hours · Maximum Marks: 70 · Attempt any five questions. All questions carry equal marks.

| Q | Question | Unit |
|---|---|---|
| 1 (a) | How many types of Information system? Explain the all types in details. | 1 |
| 1 (b) | What is Cyber Security? Describe the all information characteristics of CIA model. | 1 |
| 2 (a) | Describe in details of Ethical and professional issues of Information Security. | 1 |
| 2 (b) | How many Aspect of Information Security? Explain any four with an example. | 2 |
| 3 (a) | Describe the Security mechanism and Security Services (X.800) in details. | 2 |
| 3 (b) | How many types of Security Attacks? Explain it with an example. | 2 |
| 4 (a) | Differentiate between Substitution cipher and Transposition cipher with an example. | 3 |
| 4 (b) | Describe the one-way Hash function in details using any one Hashing algorithms. | 3 |
| 5 (a) | What is public key cryptography? Describe the RSA algorithms with an example. | 3 |
| 5 (b) | What is digital signature? Explain the Digital Signature Algorithm (DSA) in details. | 3 |
| 6 | What do you understand by watermarking? Explain it in details. | 3 |
| 7 (a) | Describe in details need of cyber security policies. | 4 |
| 7 (b) | What is Web-Security? Explain it in details. | 4 (WWW policies) |
| 8 | Write short notes on any two of the following: (i) IT Act and copyright Act (ii) Cyber Law (iii) ISO and IPR (iv) 3DES with two key. | 5 (3DES: not in syllabus) |

::: tip Notes on this paper
- **Q6 is a full 14-mark question on one topic** (watermarking). Have a 4–5 page answer ready: definition, embedding/extraction diagram, characteristics, types, applications, attacks.
- **Q7(b) "Web-Security"** maps to the syllabus line "WWW policies". Answer with web threats, SSL/TLS/HTTPS and a WWW security policy; see [Unit 4](#unit4).
- **Q8(iv) 3DES** is not in the CS-467N syllabus (it is in Stallings). It is covered in [Unit 3](#unit3) so you can attempt it, but choose the other two short notes if you can.
:::

## Syllabus (CS-467N, w.e.f. 2014-15)

| Unit | Syllabus |
|---|---|
| 1 | Introduction to Information System, Type of information system, Development of information system, CIA model of Information Characteristics, Introduction to Information Security, Need of Information Security, Cyber Security, Business need, Ethical and Professional issues of security. |
| 2 | Information Security Model, Component of an Information security, Aspect of information security, Security attacks (Active and Passive Attacks), Security mechanism and Security Services (X.800). |
| 3 | Information Security Techniques, Introduction to Cryptography: Terminology, cryptanalysis, Security of algorithms, Substitution Cipher and Transposition Cipher, Single XOR, One-way Pad, Cryptographic Protocols: Arbitrated and Adjudicated Protocol, One-Way Hash function, Public key cryptography, Digital Signature, Digital Watermarking Technique: Characteristics and Types. |
| 4 | Security Policies, Why Policies should be developed, WWW policies, Email Security policies, Policy Review Process, Corporate policies, Sample Security Policies. |
| 5 | Information Security Standards: ISO, IT Act 2000 Provisions: Introduction to digital law (cyber law, Intellectual Property, Copyright Law, Patent Law, Software License). |

**Books:** (1) *Applied Cryptography*, Bruce Schneier, John Wiley & Sons. (2) *Handbook of Information Security Management*, Micki Krause and Harold F. Tipton, CRC Press. (3) *Network Security and Cryptography*, William Stallings. Most class notes also use *Principles of Information Security*, Whitman & Mattord, for Units 1 and 2.
